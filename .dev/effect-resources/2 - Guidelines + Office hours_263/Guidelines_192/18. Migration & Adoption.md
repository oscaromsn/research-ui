## 18. Migration & Adoption

### 18.1 Migration Philosophy

#### Core Principles

Migrating to Effect-TS should be **incremental, safe, and value-driven**. The goal is to gradually introduce Effect patterns while maintaining system stability and team productivity.

**Key Migration Principles:**

1. **Start Small, Prove Value**: Begin with isolated utilities or new features
2. **Maintain Compatibility**: Keep existing code running during migration
3. **Incremental Adoption**: Migrate layer by layer, not all at once
4. **Team-Driven Pace**: Move at the speed your team can absorb
5. **Pragmatic Boundaries**: Define clear integration points between old and new code

#### Migration Readiness Assessment

Before starting migration, assess your codebase:

**Good Candidates for Effect Migration:**
- ✅ Services with complex error handling needs
- ✅ Code with many async operations and race conditions
- ✅ Systems requiring better observability
- ✅ New features or modules starting from scratch
- ✅ Code with resource management issues

**Poor Candidates for Initial Migration:**
- ❌ Stable, well-tested code with simple logic
- ❌ Performance-critical hot paths (migrate after profiling)
- ❌ Code scheduled for deprecation
- ❌ Areas with high team turnover

### 18.2 Phased Migration Strategy

#### Phase 1: Foundation Layer (Weeks 1-2)

Start by introducing Effect's type system and error handling without touching existing business logic.

**Step 1.1: Install Dependencies**


**Step 1.2: Define Error Types**

Convert generic Error classes to Effect's tagged errors:

```typescript
// BEFORE: Generic errors
class UserNotFoundError extends Error {
  constructor(public userId: string) {
    super(`User ${userId} not found`)
    this.name = "UserNotFoundError"
  }
}

// AFTER: Tagged errors
import { Data } from "effect"

class UserNotFoundError extends Data.TaggedError("UserNotFoundError")<{
  readonly userId: string
}> {}

class ValidationError extends Data.TaggedError("ValidationError")<{
  readonly field: string
  readonly message: string
}> {}

class DatabaseError extends Data.TaggedError("DatabaseError")<{
  readonly operation: string
  readonly cause: unknown
}> {}
```

**Step 1.3: Define Data Schemas**

Create schemas for domain entities:

```typescript
// BEFORE: Plain TypeScript interfaces
interface User {
  id: string
  name: string
  email: string
  createdAt: Date
}

// AFTER: Schema definitions
import * as S from "@effect/schema/Schema"

const User = S.Struct({
  id: S.UUID,
  name: S.NonEmptyString,
  email: S.String.pipe(S.pattern(/^[^\s@]+@[^\s@]+\.[^\s@]+$/)),
  createdAt: S.DateTimeUtc
})

type User = S.Schema.Type<typeof User>

// Validation at boundaries
const validateUser = (data: unknown): Effect.Effect<User, S.ParseError> =>
  S.decodeUnknown(User)(data)
```

#### Phase 2: Utility Functions (Weeks 3-4)

Convert pure utility functions and simple async operations to Effect.

**Step 2.1: Pure Function Conversion**

```typescript
// BEFORE: Functions that may throw
function parseJSON<T>(json: string): T {
  return JSON.parse(json)
}

function divide(a: number, b: number): number {
  if (b === 0) throw new Error("Division by zero")
  return a / b
}

// AFTER: Effect-based with explicit error types
import { Effect } from "effect"

class JsonParseError extends Data.TaggedError("JsonParseError")<{
  readonly input: string
  readonly cause: unknown
}> {}

class DivisionByZeroError extends Data.TaggedError("DivisionByZeroError")<{
  readonly numerator: number
}> {}

const parseJSON = <T>(json: string): Effect.Effect<T, JsonParseError> =>
  Effect.try({
    try: () => JSON.parse(json),
    catch: (cause) => new JsonParseError({ input: json, cause })
  })

const divide = (a: number, b: number): Effect.Effect<number, DivisionByZeroError> =>
  b === 0
    ? Effect.fail(new DivisionByZeroError({ numerator: a }))
    : Effect.succeed(a / b)
```

**Step 2.2: Async Function Conversion**

```typescript
// BEFORE: Promise-based functions
async function fetchUser(id: string): Promise<User> {
  const response = await fetch(`/api/users/${id}`)
  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`)
  }
  return response.json()
}

// AFTER: Effect-based with typed errors
import { Effect } from "effect"

class NetworkError extends Data.TaggedError("NetworkError")<{
  readonly url: string
  readonly status?: number
  readonly cause: unknown
}> {}

const fetchUser = (id: string): Effect.Effect<User, NetworkError | S.ParseError> =>
  Effect.gen(function* () {
    const url = `/api/users/${id}`
    
    const response = yield* Effect.tryPromise({
      try: () => fetch(url),
      catch: (cause) => new NetworkError({ url, cause })
    })

    if (!response.ok) {
      return yield* Effect.fail(
        new NetworkError({ url, status: response.status, cause: "HTTP error" })
      )
    }

    const data = yield* Effect.tryPromise({
      try: () => response.json(),
      catch: (cause) => new NetworkError({ url, cause })
    })

    return yield* S.decodeUnknown(User)(data)
  })
```

**Step 2.3: Create Compatibility Helpers**

Build adapters for gradual migration:

```typescript
// Helper to run Effects in legacy Promise code
export const runSafePromise = <A, E>(
  effect: Effect.Effect<A, E>
): Promise<A> =>
  Effect.runPromiseExit(effect).then(
    Exit.match({
      onFailure: (cause) => {
        // Convert Effect errors to Promise rejections
        const error = Cause.failureOption(cause)
        if (Option.isSome(error)) {
          return Promise.reject(error.value)
        }
        return Promise.reject(new Error("Unknown effect failure"))
      },
      onSuccess: (value) => Promise.resolve(value)
    })
  )

// Usage in legacy code
async function legacyFunction() {
  try {
    const user = await runSafePromise(fetchUser("123"))
    console.log(user)
  } catch (error) {
    console.error(error)
  }
}
```

#### Phase 3: Service Layer (Weeks 5-8)

Migrate services to use Effect's dependency injection system.

**Step 3.1: Define Service Interfaces**

```typescript
// BEFORE: Class-based service
class UserRepository {
  constructor(private db: Database) {}

  async findById(id: string): Promise<User | null> {
    const row = await this.db.query(
      "SELECT * FROM users WHERE id = $1",
      [id]
    )
    return row ? this.mapToUser(row) : null
  }

  async create(user: NewUser): Promise<User> {
    const row = await this.db.query(
      "INSERT INTO users (name, email) VALUES ($1, $2) RETURNING *",
      [user.name, user.email]
    )
    return this.mapToUser(row)
  }

  private mapToUser(row: any): User {
    return {
      id: row.id,
      name: row.name,
      email: row.email,
      createdAt: new Date(row.created_at)
    }
  }
}

// AFTER: Effect service
import { Context, Effect, Layer } from "effect"

interface UserRepository {
  readonly findById: (id: string) => Effect.Effect<Option.Option<User>, DatabaseError>
  readonly create: (user: NewUser) => Effect.Effect<User, DatabaseError | ValidationError>
}

class UserRepository extends Context.Tag("@app/UserRepository")
  UserRepository,
  UserRepository
>() {}
```

**Step 3.2: Implement Service Layer**

```typescript
const makeUserRepository = Effect.gen(function* () {
  const db = yield* Database
  const logger = yield* Logger

  const findById = (id: string): Effect.Effect<Option.Option<User>, DatabaseError> =>
    Effect.gen(function* () {
      yield* logger.debug("Finding user by ID", { userId: id })

      const result = yield* Effect.tryPromise({
        try: () => db.query("SELECT * FROM users WHERE id = $1", [id]),
        catch: (cause) => new DatabaseError({ operation: "findById", cause })
      })

      if (!result) {
        return Option.none()
      }

      const user = yield* S.decodeUnknown(User)(result)
      return Option.some(user)
    })

  const create = (newUser: NewUser): Effect.Effect<User, DatabaseError | ValidationError> =>
    Effect.gen(function* () {
      // Validate input
      const validated = yield* S.decodeUnknown(NewUserSchema)(newUser)

      yield* logger.info("Creating user", { email: validated.email })

      const result = yield* Effect.tryPromise({
        try: () => db.query(
          "INSERT INTO users (name, email) VALUES ($1, $2) RETURNING *",
          [validated.name, validated.email]
        ),
        catch: (cause) => new DatabaseError({ operation: "create", cause })
      })

      return yield* S.decodeUnknown(User)(result)
    })

  return UserRepository.of({ findById, create })
})

export const UserRepositoryLive = Layer.effect(UserRepository, makeUserRepository)
```

**Step 3.3: Gradual Service Migration**

Migrate services one at a time, maintaining compatibility:

```typescript
// Wrapper for legacy code to use new Effect services
class UserServiceAdapter {
  private runtime: Runtime.Runtime<UserRepository>

  constructor() {
    this.runtime = Layer.toRuntime(UserRepositoryLive).pipe(
      Effect.scoped,
      Effect.runSync
    )
  }

  async findById(id: string): Promise<User | null> {
    const effect = Effect.gen(function* () {
      const repo = yield* UserRepository
      const result = yield* repo.findById(id)
      return Option.getOrNull(result)
    })

    return Runtime.runPromise(this.runtime)(effect)
  }

  async create(user: NewUser): Promise<User> {
    const effect = Effect.gen(function* () {
      const repo = yield* UserRepository
      return yield* repo.create(user)
    })

    return Runtime.runPromise(this.runtime)(effect)
  }
}

// Use adapter in legacy code
export const userService = new UserServiceAdapter()
```

```typescript
const api = HttpApi.empty.pipe(

    HttpApiGroup.make("users").pipe(
      HttpApiGroup.add(
        HttpApiEndpoint.get("getUser", "/users/:id")

            HttpApiEndpoint.addError(UserNotFoundError)

class UsersHandlers extends Effect.Service<UsersHandlers>()(
  "app/UsersHandlers",
  {
    effect: Effect.gen(function* () {
      const repo = yield* UserRepository

      return HttpApiBuilder.group(api, "users", {
        getUser: ({ path }) =>
          Effect.gen(function* () {
            const user = yield* repo.findById(path.id)

            if (Option.isNone(user)) {
```

```typescript
      bio: validated.bio,
```

### 18.3 Converting Code Patterns

#### 18.3.1 Promise to Effect Conversion

**Pattern 1: Simple Promise**

```typescript
// BEFORE
async function fetchData(): Promise<Data> {
  return fetch("/api/data").then(r => r.json())
}

// AFTER
const fetchData = (): Effect.Effect<Data, NetworkError> =>
  Effect.tryPromise({
    try: () => fetch("/api/data").then(r => r.json()),
    catch: (cause) => new NetworkError({ cause })
  })
```

**Pattern 2: Promise with Error Handling**

```typescript
// BEFORE
async function saveUser(user: User): Promise<void> {
  try {
    await db.insert("users", user)
  } catch (error) {
    if (error.code === "UNIQUE_VIOLATION") {
      throw new Error("User already exists")
    }
    throw new Error("Database error")
  }
}

// AFTER
const saveUser = (user: User): Effect.Effect<void, DatabaseError> =>
  Effect.gen(function* () {
    yield* Effect.tryPromise({
      try: () => db.insert("users", user),
      catch: (error: any) => {
        if (error.code === "UNIQUE_VIOLATION") {
          return new DatabaseError({
            operation: "insert",
            cause: "User already exists"
          })
        }
        return new DatabaseError({
          operation: "insert",
          cause: error
        })
      }
    })
  })
```

```typescript
// BEFORE
async function processUser(id: string): Promise<Result> {
```

**Pattern 2: Try/Catch to Effect Error Handling**

```typescript
// BEFORE
async function processOrder(order: Order): Promise<Receipt> {
  try {
    await validateOrder(order)
    const payment = await processPayment(order)
    const receipt = await generateReceipt(payment)
    return receipt
  } catch (error) {
    if (error instanceof ValidationError) {
      throw new OrderError("Validation failed")
    }
    if (error instanceof PaymentError) {
      throw new OrderError("Payment failed")
    }
    throw error
  }
}

// AFTER
const processOrder = (order: Order): Effect.Effect<Receipt, OrderError> =>
  Effect.gen(function* () {
    yield* validateOrder(order)
    const payment = yield* processPayment(order)
    const receipt = yield* generateReceipt(payment)
    return receipt
  }).pipe(
    Effect.catchTags({
      ValidationError: (error) =>
        Effect.fail(new OrderError({ message: "Validation failed", cause: error })),
      PaymentError: (error) =>
        Effect.fail(new OrderError({ message: "Payment failed", cause: error }))
    })
  )
```

**Pattern 3: Conditional Logic**

```typescript
// BEFORE
async function getOrCreateUser(email: string): Promise<User> {
  let user = await findUserByEmail(email)
  
  if (!user) {
    user = await createUser({ email, name: email.split("@")[0] })
  }
  
  if (!user.verified) {
    await sendVerificationEmail(user)
  }
  
  return user
}

// AFTER
const getOrCreateUser = (email: string): Effect.Effect<User, DatabaseError | EmailError> =>
  Effect.gen(function* () {
    const userOpt = yield* findUserByEmail(email)
    
    const user = Option.match(userOpt, {
      onNone: () => createUser({ email, name: email.split("@")[0] }),
      onSome: (u) => Effect.succeed(u)
    })
    
    const existingUser = yield* user
    
    if (!existingUser.verified) {
      yield* Effect.fork(sendVerificationEmail(existingUser))
    }
    
    return existingUser
  })
```

#### 18.3.3 Callback to Effect Conversion

**Pattern 1: Node.js Callback Style**

```typescript
// BEFORE
import fs from "fs"

function readFileCallback(path: string, callback: (err: Error | null, data: string | null) => void) {
  fs.readFile(path, "utf8", (err, data) => {
    if (err) {
      callback(err, null)
    } else {
      callback(null, data)
    }
  })
}

// AFTER
import { Effect } from "effect"
import fs from "fs"

class FileSystemError extends Data.TaggedError("FileSystemError")<{
  readonly path: string
  readonly cause: unknown
}> {}

const readFile = (path: string): Effect.Effect<string, FileSystemError> =>
  Effect.async<string, FileSystemError>((resume) => {
    fs.readFile(path, "utf8", (err, data) => {
      if (err) {
        resume(Effect.fail(new FileSystemError({ path, cause: err })))
      } else {
        resume(Effect.succeed(data))
      }
    })
  })
```

**Pattern 2: Event Emitter Pattern**

```typescript
// BEFORE
import { EventEmitter } from "events"

function waitForEvent(emitter: EventEmitter, eventName: string): Promise<any> {
  return new Promise((resolve, reject) => {
    const timeout = setTimeout(() => {
      reject(new Error("Timeout waiting for event"))
    }, 5000)
    
    emitter.once(eventName, (data) => {
      clearTimeout(timeout)
      resolve(data)
    })
    
    emitter.once("error", (error) => {
      clearTimeout(timeout)
      reject(error)
    })
  })
}

// AFTER
import { Effect } from "effect"
import { EventEmitter } from "events"

class EventTimeoutError extends Data.TaggedError("EventTimeoutError")<{
  readonly eventName: string
}> {}

class EventEmitterError extends Data.TaggedError("EventEmitterError")<{
  readonly cause: unknown
}> {}

const waitForEvent = (
  emitter: EventEmitter,
  eventName: string
): Effect.Effect<unknown, EventTimeoutError | EventEmitterError> =>
  Effect.async<unknown, EventTimeoutError | EventEmitterError>((resume) => {
    const cleanup = () => {
      emitter.removeListener(eventName, onEvent)
      emitter.removeListener("error", onError)
    }
    
    const onEvent = (data: unknown) => {
      cleanup()
      resume(Effect.succeed(data))
    }
    
    const onError = (error: unknown) => {
      cleanup()
      resume(Effect.fail(new EventEmitterError({ cause: error })))
    }
    
    emitter.once(eventName, onEvent)
    emitter.once("error", onError)
    
    // Return cleanup function
    return Effect.sync(() => cleanup())
  }).pipe(
    Effect.timeout("5 seconds"),
    Effect.catchTag("TimeoutException", () =>
      Effect.fail(new EventTimeoutError({ eventName }))
    )
  )
```

**Pattern 3: Custom Callback API**

```typescript
// BEFORE
interface ApiCallback {
  onSuccess: (data: Data) => void
  onError: (error: Error) => void

function fetchWithCallback(url: string, callbacks: ApiCallback): void {

// AFTER
```

### 18.4 Legacy Integration Patterns

#### 18.4.1 Wrapping Existing Services

**Pattern: Service Facade**

```typescript
// Legacy service implementation
class LegacyUserService {
  private db: LegacyDatabase
  
  constructor(db: LegacyDatabase) {
    this.db = db
  }
  
  async getUser(id: string): Promise<LegacyUser> {
    return this.db.query("SELECT * FROM users WHERE id = $1", [id])
  }
  
  async updateUser(id: string, updates: Partial<LegacyUser>): Promise<void> {
    await this.db.query(
      "UPDATE users SET name = $1, email = $2 WHERE id = $3",
      [updates.name, updates.email, id]
    )
  }
}

// Effect wrapper
class EffectUserService extends Context.Tag("@app/UserService")
  EffectUserService,
  {
    readonly getUser: (id: string) => Effect.Effect<User, UserNotFoundError | DatabaseError>
    readonly updateUser: (id: string, updates: Partial<User>) => Effect.Effect<void, UserNotFoundError | DatabaseError>
  }
>() {}

const makeLegacyServiceWrapper = (legacy: LegacyUserService) =>
  Effect.gen(function* () {
    const logger = yield* Logger

    const getUser = (id: string): Effect.Effect<User, UserNotFoundError | DatabaseError> =>
      Effect.gen(function* () {
        yield* logger.debug("Fetching user from legacy service", { userId: id })

        const legacyUser = yield* Effect.tryPromise({
          try: () => legacy.getUser(id),
          catch: (cause) => new DatabaseError({ operation: "getUser", cause })
        })

        if (!legacyUser) {
          return yield* Effect.fail(new UserNotFoundError({ userId: id }))
        }

        // Transform legacy format to new format
        return yield* S.decodeUnknown(User)({
          id: legacyUser.id,
          name: legacyUser.name,
          email: legacyUser.email,
          createdAt: new Date(legacyUser.created_at)
        })
      })

    const updateUser = (id: string, updates: Partial<User>): Effect.Effect<void, UserNotFoundError | DatabaseError> =>
      Effect.gen(function* () {
        // Verify user exists first
        yield* getUser(id)

        yield* Effect.tryPromise({
          try: () => legacy.updateUser(id, {
            name: updates.name,
            email: updates.email
          }),
          catch: (cause) => new DatabaseError({ operation: "updateUser", cause })
        })
      })

    return EffectUserService.of({ getUser, updateUser })
  })
```

#### 18.4.2 Database Migration Patterns

**Pattern: Gradual Query Migration**

```typescript
// Phase 1: Wrap existing ORM/query builder
import { QueryBuilder } from "legacy-orm"

class Database extends Context.Tag("@app/Database")
  Database,
  {
    readonly query: <T>(sql: string, params: unknown[]) => Effect.Effect<T, DatabaseError>
    readonly transaction: <A, E, R>(
      effect: Effect.Effect<A, E, R>
    ) => Effect.Effect<A, E | DatabaseError, R>
  }
>() {}

const makeDatabaseService = Effect.gen(function* () {
  const config = yield* Config
  const logger = yield* Logger

  const pool = yield* Effect.acquireRelease(
    Effect.sync(() => {
      logger.info("Creating database pool")
      return new QueryBuilder(config.database)
    }),
    (pool) =>
      Effect.sync(() => {
        logger.info("Closing database pool")
        pool.close()
      })
  )

  const query = <T>(sql: string, params: unknown[]): Effect.Effect<T, DatabaseError> =>
    Effect.tryPromise({
      try: () => pool.query(sql, params) as Promise<T>,
      catch: (cause) => new DatabaseError({ operation: "query", cause })
    })

  const transaction = <A, E, R>(
    effect: Effect.Effect<A, E, R>
  ): Effect.Effect<A, E | DatabaseError, R> =>
    Effect.gen(function* () {
      yield* Effect.tryPromise({
        try: () => pool.beginTransaction(),
        catch: (cause) => new DatabaseError({ operation: "beginTransaction", cause })
      })

      const result = yield* effect.pipe(
        Effect.catchAll((error) =>
          Effect.gen(function* () {
            yield* Effect.tryPromise({
              try: () => pool.rollback(),
              catch: (cause) => new DatabaseError({ operation: "rollback", cause })
            })
            return yield* Effect.fail(error)
          })
        )
      )

      yield* Effect.tryPromise({
        try: () => pool.commit(),
        catch: (cause) => new DatabaseError({ operation: "commit", cause })
      })

      return result
    })

  return Database.of({ query, transaction })
})

export const DatabaseLive = Layer.scoped(Database, makeDatabaseService)

// Phase 2: Gradually migrate to @effect/sql
import { SqlClient } from "@effect/sql"

const makeEffectSqlService = Effect.gen(function* () {
  const sql = yield* SqlClient.SqlClient

  return Database.of({
    query: (sqlString, params) =>
      sql.unsafe(sqlString, params).pipe(
        Effect.mapError((cause) => new DatabaseError({ operation: "query", cause }))
      ),
    transaction: (effect) =>
      sql.withTransaction(effect).pipe(
        Effect.mapError((cause) => new DatabaseError({ operation: "transaction", cause }))
      )
  })
})
```

- ✅ Use compatibility layers for gradual transition

- ✅ Pair experienced and junior developers

**DON'T:**

- ❌ Force full codebase rewrite
- ❌ Skip testing during migration

- ❌ Create tight coupling between old and new
- ❌ Ignore team feedback and concerns
- ❌ Migrate without understanding Effect patterns
- ❌ Skip documentation and training

#### 18.6.2 Common Pitfalls

**Pitfall 1: Over-Engineering**

```typescript
// ❌ DON'T: Over-abstract before understanding needs
const withLogging = <A, E, R>(
  effect: Effect.Effect<A, E, R>
): Effect.Effect<A, E, R | Logger> =>
  Effect.gen(function* () {
    const logger = yield* Logger
    yield* logger.info("Starting operation")
    const result = yield* effect
    yield* logger.info("Completed operation")
    return result
  })

// ✅ DO: Start simple, abstract when pattern emerges
const getUserWithLogging = (id: string) =>
  Effect.gen(function* () {
    yield* Effect.log("Getting user", { userId: id })
    const user = yield* getUser(id)
    yield* Effect.log("User retrieved", { userId: id })
    return user
  })
```

**Pitfall 2: Mixing Paradigms**

```typescript
// ❌ DON'T: Mix async/await with Effect
const badMix = async (id: string) => {
  const user = await Effect.runPromise(getUser(id)) // Bad
  const profile = await getProfile(user.profileId)   // Inconsistent
  return { user, profile }
}

// ✅ DO: Use Effect consistently
const goodPattern = (id: string) =>
  Effect.gen(function* () {
    const user = yield* getUser(id)
    const profile = yield* getProfile(user.profileId)
    return { user, profile }
  })
```

**Pitfall 3: Ignoring Error Channel**

```typescript
// ❌ DON'T: Catch all errors generically
const badErrorHandling = (id: string) =>
  getUser(id).pipe(
    Effect.catchAll(() => Effect.succeed(defaultUser)) // Loses error information
  )

// ✅ DO: Handle specific errors appropriately
const goodErrorHandling = (id: string) =>
  getUser(id).pipe(
    Effect.catchTag("UserNotFoundError", () => Effect.succeed(defaultUser)),
    Effect.catchTag("DatabaseError", (error) => Effect.fail(error)) // Propagate serious errors
  )
```

**Pitfall 4: Resource Leaks**

```typescript
// ❌ DON'T: Forget resource cleanup
const leakyResource = Effect.gen(function* () {
  const connection = yield* openConnection()
  const result = yield* useConnection(connection)
  // Connection never closed!
  return result
})

// ✅ DO: Use proper resource management
const safeResource = Effect.acquireRelease(
  openConnection(),
  (connection) => closeConnection(connection)
).pipe(
  Effect.flatMap((connection) => useConnection(connection))
)
```

### 18.8 Rollback Strategy

**When to Rollback:**
- Significant performance degradation (>20%)
- Increased error rates in production
- Team unable to maintain code effectively
- Critical bugs introduced by migration

**How to Rollback:**

```typescript
// Use feature flags for gradual rollout
const getUser = (id: string) =>
  Effect.gen(function* () {
    const flags = yield* FeatureFlags
    const useEffectVersion = yield* flags.isEnabled("effect-user-service")

    if (useEffectVersion) {
      return yield* newEffectUserService.getUser(id)
    } else {
      // Fallback to legacy implementation
      return yield* Effect.tryPromise({
        try: () => legacyUserService.getUser(id),
        catch: (error) => new DatabaseError({ cause: error })
      })
    }
  })
```

**Progressive Rollout:**
1. Deploy to 1% of traffic
2. Monitor metrics for 24 hours
3. Increase to 10% if stable
4. Continue gradual increase to 100%
5. Keep legacy code for 1-2 sprints after full rollout
