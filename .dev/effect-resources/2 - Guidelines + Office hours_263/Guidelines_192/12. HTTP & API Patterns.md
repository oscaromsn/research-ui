# 12. HTTP & API Patterns

## 12.1 HTTP APIs (@effect/platform)

### Core Principle

Define type-safe HTTP APIs using `HttpApi` from `@effect/platform` to ensure compile-time validation of endpoints, payloads, and responses.

### Defining HTTP API Specifications

```typescript
import { HttpApi, HttpApiEndpoint, HttpApiGroup } from "@effect/platform"
import { Schema } from "@effect/schema"

// Define API specification with type-safe endpoints
export const api = HttpApi.empty.pipe(
  HttpApi.addGroup(
    HttpApiGroup.make("products").pipe(
      // GET endpoint with path parameter
      HttpApiGroup.add(
        HttpApiEndpoint.get("getById", "/products/:id").pipe(
          HttpApiEndpoint.addSuccess(ProductSchema),
          HttpApiEndpoint.addError(Schema.String)
        )
      ),
      // GET endpoint with query parameters
      HttpApiGroup.add(
        HttpApiEndpoint.get("getAll", "/products").pipe(
          HttpApiEndpoint.addSuccess(Schema.Array(ProductSchema)),
          HttpApiEndpoint.addError(Schema.String)
        )
      ),
      // POST endpoint with payload
      HttpApiGroup.add(
        HttpApiEndpoint.post("create", "/products").pipe(
          HttpApiEndpoint.setPayload(CreateProductSchema),
          HttpApiEndpoint.addSuccess(ProductSchema),
          HttpApiEndpoint.addError(ValidationErrorSchema)
        )
      ),
      // PUT endpoint with path parameter and payload
      HttpApiGroup.add(
        HttpApiEndpoint.put("update", "/products/:id").pipe(
          HttpApiEndpoint.setPayload(UpdateProductSchema),
          HttpApiEndpoint.addSuccess(ProductSchema),
          HttpApiEndpoint.addError(Schema.Union(NotFoundErrorSchema, ValidationErrorSchema))
        )
      ),
      // DELETE endpoint
      HttpApiGroup.add(
        HttpApiEndpoint.del("delete", "/products/:id").pipe(
          HttpApiEndpoint.addSuccess(Schema.Void),
          HttpApiEndpoint.addError(NotFoundErrorSchema)
        )
      )
    )
  )
)
```

### Handler Implementation

```typescript
import { HttpApiBuilder } from "@effect/platform"
import { Effect } from "effect"

// Implement API handlers
export class ProductHandlers extends Effect.Service<ProductHandlers>()(
  "app/ProductHandlers",
  {
    effect: Effect.gen(function* () {
      const productService = yield* ProductService

      return HttpApiBuilder.group(api, "products", {
        getById: ({ path }) =>
          productService.getById(path.id).pipe(
            Effect.catchTag("ProductNotFound", (error) =>
              Effect.fail(
                new NotFoundError({
                  resourceType: "Product",
                  resourceId: error.id
                })
              )
            )
          ),

        getAll: () =>
          productService.getAll(),

        create: ({ payload }) =>
          productService.create(payload).pipe(
            Effect.catchTag("ValidationError", (error) =>
              Effect.fail(error)
            )
          ),

        update: ({ path, payload }) =>
          productService.update(path.id, payload).pipe(
            Effect.catchTags({
              ProductNotFound: (error) =>
                Effect.fail(
                  new NotFoundError({
                    resourceType: "Product",
                    resourceId: error.id
                  })
                ),
              ValidationError: (error) =>
                Effect.fail(error)
            })
          ),

        delete: ({ path }) =>
          productService.delete(path.id).pipe(
            Effect.catchTag("ProductNotFound", (error) =>
              Effect.fail(
                new NotFoundError({
                  resourceType: "Product",
                  resourceId: error.id
                })
              )
            )
          )
      })
    }),
    dependencies: [ProductService.Default]
  }
) {}
```

### API Handler with Complex Logic

```typescript
// Handler with validation, authorization, and business logic
export class OrderHandlers extends Effect.Service<OrderHandlers>()(
  "app/OrderHandlers",
  {
    effect: Effect.gen(function* () {
      const orderService = yield* OrderService
      const authService = yield* AuthService

      return HttpApiBuilder.group(api, "orders", {
        create: ({ payload, headers }) =>
          Effect.gen(function* () {
            // Extract and validate auth token
            const token = headers.authorization?.replace("Bearer ", "")
            if (!token) {
              return yield* Effect.fail(
                new UnauthorizedError({ message: "Missing authentication token" })
              )
            }

            // Verify token and get user
            const user = yield* authService.verifyToken(token).pipe(
              Effect.catchTag("InvalidToken", () =>
                Effect.fail(new UnauthorizedError({ message: "Invalid token" }))
              )
            )

            // Create order with user context
            const order = yield* orderService.create({
              ...payload,
              userId: user.id
            })

            return order
          }),

        getById: ({ path, headers }) =>
          Effect.gen(function* () {
            const user = yield* authService.getCurrentUser(headers)
            const order = yield* orderService.getById(path.id)

            // Ensure user can access this order
            if (order.userId !== user.id && !user.isAdmin) {
              return yield* Effect.fail(
                new ForbiddenError({ message: "Access denied" })
              )
            }

            return order
          })
      })
    }),
    dependencies: [OrderService.Default, AuthService.Default]
  }
) {}
```

### Custom Middleware Patterns

```typescript
// Create custom authentication middleware
const authMiddleware = HttpMiddleware.make((app) =>
  Effect.gen(function* () {
    const authService = yield* AuthService

    return (request) =>
      Effect.gen(function* () {
        // Extract token from header
        const token = request.headers.authorization?.replace("Bearer ", "")

        if (!token) {
          return HttpServerResponse.json(
            { error: "Missing authentication token" },
            { status: 401 }
          )
        }

        // Verify token
        const user = yield* authService.verifyToken(token).pipe(
          Effect.catchAll(() =>
            Effect.succeed(
              HttpServerResponse.json(
                { error: "Invalid token" },
                { status: 401 }
              )
            )
          )
        )

        // Add user to request context
        return yield* app(request).pipe(
          Effect.provideService(CurrentUser, user)
        )
      })
  })
)

// Create request timing middleware
const timingMiddleware = HttpMiddleware.make((app) =>
  (request) =>
    Effect.gen(function* () {
      const start = Date.now()

      const response = yield* app(request)

      const duration = Date.now() - start

      yield* Effect.log("Request processed", {
        path: request.url,
        method: request.method,
        duration: `${duration}ms`,
        status: response.status
      })

      return response
    })
)

// Compose middleware
const HttpLive = HttpApiBuilder.serve().pipe(
  Layer.provide(authMiddleware),
  Layer.provide(timingMiddleware),
  Layer.provide(HttpMiddleware.logger),
  Layer.provide(ApiLive),
```

### Error Response Patterns

```typescript
// Standardized error responses
const handleApiError = (error: unknown) => {
  if (error instanceof ValidationError) {
    return HttpServerResponse.json(
      {
        error: "Validation failed",
        field: error.field,
        message: error.message
      },
      { status: 400 }
    )
  }

  if (error instanceof NotFoundError) {
    return HttpServerResponse.json(
      {
        error: "Resource not found",
        resourceType: error.resourceType,
        resourceId: error.resourceId
      },
      { status: 404 }
    )
  }

  if (error instanceof UnauthorizedError) {
    return HttpServerResponse.json(
      { error: "Unauthorized", message: error.message },
      { status: 401 }
    )
  }

  // Default error response
  return HttpServerResponse.json(
    { error: "Internal server error" },
    { status: 500 }
  )
}

// Use in handlers
const handler = (req: HttpServerRequest.HttpServerRequest) =>
  Effect.gen(function* () {
    const service = yield* ProductService
    const product = yield* service.getById(req.params.id)
    return HttpServerResponse.json(product)
  }).pipe(
    Effect.catchAll(handleApiError)
  )
```

```typescript
// Client with automatic token refresh
export class AuthenticatedApiClient extends Effect.Service<AuthenticatedApiClient>()(
  "app/AuthenticatedApiClient",
  {
    effect: Effect.gen(function* () {
      const authService = yield* AuthService
      const config = yield* Config

    }),
```

### Circuit Breaker Pattern

```typescript
// Client with circuit breaker for resilience
const makeResilientClient = Effect.gen(function* () {
  const config = yield* Config

  // Track failures
  const failureCount = yield* Ref.make(0)
  const lastFailureTime = yield* Ref.make<number | null>(null)

  const isCircuitOpen = Effect.gen(function* () {
    const failures = yield* Ref.get(failureCount)
    const lastFailure = yield* Ref.get(lastFailureTime)

    // Open circuit after 5 failures
    if (failures >= 5) {
      // Close circuit after 30 seconds
      if (lastFailure && Date.now() - lastFailure < 30000) {
        return true
      }
      // Reset after cooldown
      yield* Ref.set(failureCount, 0)
      yield* Ref.set(lastFailureTime, null)
    }

    return false
  })

  const client = HttpClient.HttpClient.pipe(
    HttpClient.mapRequest(
      HttpClientRequest.prependUrl(config.apiBaseUrl)
    ),
    // Check circuit before making request
    HttpClient.filterStatusOk,
    HttpClient.tapErrorCause((cause) =>
      Effect.gen(function* () {
        yield* Ref.update(failureCount, (n) => n + 1)
        yield* Ref.set(lastFailureTime, Date.now())
        yield* Effect.logError("Request failed", { cause })
      })
    )
  )

  const execute = <A, E>(
    request: Effect.Effect<A, E, never>
  ): Effect.Effect<A, E | CircuitOpenError, never> =>
    Effect.gen(function* () {
      const open = yield* isCircuitOpen

      if (open) {
        return yield* Effect.fail(
          new CircuitOpenError({ message: "Circuit breaker is open" })
        )
      }

      return yield* request
    })

  return { client, execute } as const
})
```

```typescript
              HttpClientResponse.schemaBodyJson(Schema.Array(ProductSchema))

          )
        })

          yield* logger.info("Creating product", { product })

            .post("/products", {
              body: HttpBody.json(product)

                logger.info("Product created", { id: created.id })
              )
            )

          return yield* baseClient

              body: HttpBody.json(updates)

        listProducts,
        createProduct,
        updateProduct,
        deleteProduct
      } as const
    }),
    dependencies: [Config.Default, Logger.Default]
  }
```

```typescript
// Define domain-specific API errors
export class ApiError extends Schema.TaggedError<ApiError>()(
  "ApiError",
  {
    message: Schema.String,
    statusCode: Schema.optional(Schema.Number),
    cause: Schema.optional(Schema.Unknown)
  }
) {}

export class RateLimitError extends Schema.TaggedError<RateLimitError>()(
  "RateLimitError",
  {
    retryAfter: Schema.Number
  }
) {}

// Client with sophisticated error handling
const makeResilientApiClient = Effect.gen(function* () {
  const baseClient = HttpClient.HttpClient

  const withErrorMapping = <A>(
    request: Effect.Effect<A, HttpClientResponse.HttpClientResponse, never>
  ) =>
    request.pipe(
      Effect.catchTag("ResponseError", (error) => {
        const status = error.response.status

        // Map specific status codes to domain errors
        if (status === 429) {
          const retryAfter = parseInt(
            error.response.headers["retry-after"] || "60"
          )
          return Effect.fail(new RateLimitError({ retryAfter }))
        }

        if (status === 401) {
          return Effect.fail(new UnauthorizedError())
        }

        if (status === 403) {
          return Effect.fail(new ForbiddenError())
        }

        if (status >= 500) {
          return Effect.fail(
            new ApiError({
              message: "Server error",
              statusCode: status,
              cause: error
            })
          )
        }

        return Effect.fail(
          new ApiError({
            message: "Client error",
            statusCode: status,
            cause: error
          })
        )
      })
    )

  const withRetry = <A, E, R>(
    effect: Effect.Effect<A, E, R>
  ): Effect.Effect<A, E, R> =>
    effect.pipe(
      Effect.retry({
        // Retry on rate limit errors with exponential backoff
        while: (error) =>
          error instanceof RateLimitError ||
          (error instanceof ApiError && error.statusCode && error.statusCode >= 500),
        times: 3,
        schedule: Schedule.exponential("1 second")
      })
    )

  return { baseClient, withErrorMapping, withRetry } as const
})
```

### Authentication Patterns

```typescript
// Token management service
export class TokenManager extends Effect.Service<TokenManager>()(
  "app/TokenManager",
  {
    effect: Effect.gen(function* () {
      const tokens = yield* Ref.make<{
        accessToken: string | null
        refreshToken: string | null
        expiresAt: number | null
      }>({
        accessToken: null,
        refreshToken: null,
        expiresAt: null
      })

      const getAccessToken = Effect.gen(function* () {
        const current = yield* Ref.get(tokens)

        // Check if token is expired
        if (current.expiresAt && Date.now() >= current.expiresAt) {
          yield* refreshAccessToken
        }

        const updated = yield* Ref.get(tokens)
        return updated.accessToken
      })

      const refreshAccessToken = Effect.gen(function* () {
        const current = yield* Ref.get(tokens)

        if (!current.refreshToken) {
          return yield* Effect.fail(new TokenExpiredError())
        }

        const response = yield* HttpClient.HttpClient.post("/auth/refresh", {
          body: HttpBody.json({ refreshToken: current.refreshToken })
        }).pipe(
          Effect.flatMap(
            HttpClientResponse.schemaBodyJson(RefreshTokenResponseSchema)
          )
        )

        yield* Ref.set(tokens, {
          accessToken: response.accessToken,
          refreshToken: response.refreshToken,
          expiresAt: Date.now() + response.expiresIn * 1000
        })
      })

      const setTokens = (accessToken: string, refreshToken: string, expiresIn: number) =>
        Ref.set(tokens, {
          accessToken,
          refreshToken,
          expiresAt: Date.now() + expiresIn * 1000
        })

      return {
        getAccessToken,
        refreshAccessToken,
        setTokens
      } as const
    })
  }
) {}

// Authenticated API client
export class AuthenticatedApiClient extends Effect.Service<AuthenticatedApiClient>()(
  "app/AuthenticatedApiClient",
  {
    effect: Effect.gen(function* () {
      const tokenManager = yield* TokenManager
      const config = yield* Config

      const client = HttpClient.HttpClient.pipe(
        HttpClient.mapRequest(
          HttpClientRequest.prependUrl(config.apiBaseUrl)
        ),
        // Inject auth token
        HttpClient.mapRequest((request) =>
          Effect.gen(function* () {
            const token = yield* tokenManager.getAccessToken()

            if (!token) {
              return yield* Effect.fail(new UnauthorizedError())
            }

            return HttpClientRequest.setHeader(
              request,
              "Authorization",
              `Bearer ${token}`
            )
          })
        ),
        // Handle 401 by refreshing token
        HttpClient.catchTag("ResponseError", (error) =>
          error.response.status === 401
            ? Effect.gen(function* () {
                yield* tokenManager.refreshAccessToken()
                // Retry with new token
                return yield* HttpClient.HttpClient.execute(error.request)
              })
            : Effect.fail(error)
        ),
        HttpClient.filterStatusOk
      )

      return { client } as const
    }),
    dependencies: [TokenManager.Default, Config.Default]
  }
) {}
```

## Best Practices

### 1. API Design

- **Type Safety First**: Define all endpoints, payloads, and responses with schemas
- **Consistent Naming**: Use clear, consistent naming for endpoints and operations
- **Version APIs**: Plan for API evolution with versioning strategies
- **Document Schemas**: Add JSDoc comments to all schema definitions
- **Error Handling**: Define specific error types for different failure scenarios

### 2. HTTP Client Patterns

- **Centralized Configuration**: Configure clients once, reuse across application
- **Schema Validation**: Validate all responses with schemas
- **Error Mapping**: Map HTTP errors to domain-specific errors
- **Retry Logic**: Implement intelligent retry strategies
- **Authentication**: Handle token management and refresh transparently

### 3. Server Configuration

- **Middleware Composition**: Build servers with composable middleware layers
- **Observability**: Include logging, tracing, and monitoring middleware
- **Error Handling**: Implement consistent error response patterns
- **Security**: Add authentication, authorization, and rate limiting
- **Performance**: Configure appropriate timeouts and concurrency limits

### 4. Schema Management

- **Reusable Schemas**: Create shared schema libraries for common patterns
- **Validation at Boundaries**: Validate all external data with schemas
- **Versioning**: Support multiple API versions with schema migrations
- **Backward Compatibility**: Use optional fields for non-breaking changes
- **Documentation**: Document schema fields and validation rules

### 5. Testing

- **Mock HTTP Servers**: Use test layers for HTTP server testing
- **Mock HTTP Clients**: Create mock layers for external API clients
- **Schema Testing**: Test schema validation with valid and invalid data
- **Error Testing**: Test all error scenarios and recovery mechanisms
- **Integration Testing**: Test complete request/response flows
