## 11. Performance Optimization

### Core Philosophy

Performance optimization in Effect-TS follows a principle-driven approach: **measure first, optimize strategically, and maintain code clarity**. Effect provides powerful primitives for batching, caching, and concurrency control that enable high-performance applications while preserving type safety and composability.

**Key Principles:**
- **Measure Before Optimizing**: Profile to identify actual bottlenecks, not perceived ones
- **Strategic Optimization**: Focus on hot paths and critical operations
- **Maintain Clarity**: Performance improvements should not sacrifice code readability
- **Built-in Primitives**: Leverage Effect's optimized implementations over custom solutions
- **Appropriate Limits**: Set concurrency and capacity limits to prevent resource exhaustion

### 11.1 Request Batching

Request batching consolidates multiple individual requests into single operations, dramatically reducing overhead when communicating with databases, APIs, or other external systems.

#### RequestResolver Pattern

The `RequestResolver` pattern provides automatic request batching and deduplication:

```typescript
import { Effect, Request, RequestResolver } from "effect"

// 1. Define the request type
interface GetUser extends Request.Request<User, UserNotFoundError> {
  readonly _tag: "GetUser"
  readonly id: string
}

const GetUser = Request.tagged<GetUser>("GetUser")

// 2. Create batched resolver
const UserResolver = RequestResolver.makeBatched(
  (requests: GetUser[]) =>
    Effect.gen(function* () {
      // Extract all IDs from the batch
      const ids = requests.map(req => req.id)
      
      yield* Effect.logInfo(`Batching ${requests.length} user requests`, { ids })

      // Single database query for all users
      const users = yield* database.query(
        `SELECT * FROM users WHERE id IN (${ids.map(() => '?').join(',')})`,
        ids
      )

      // Map results to a lookup structure
      const userMap = new Map(users.map(u => [u.id, u]))

      // Fulfill each individual request
      return Effect.forEach(requests, (req) => {
        const user = userMap.get(req.id)
        
        return user
          ? Request.succeed(req, user)
          : Request.fail(req, new UserNotFoundError({ userId: req.id }))
      })
    })
)

// 3. Use the batched resolver
const getUsersBatched = (ids: string[]) =>
  Effect.all(
    ids.map(id => Effect.request(GetUser({ id }), UserResolver)),
    { concurrency: "unbounded" }
  )

// Example: These 100 requests become just 1 database query
const program = Effect.gen(function* () {
  const userIds = Array.from({ length: 100 }, (_, i) => `user-${i}`)
  const users = yield* getUsersBatched(userIds)
  
  yield* Effect.logInfo(`Retrieved ${users.length} users with 1 query`)
  return users
})
```

#### Advanced Batching: Multiple Request Types

```typescript
// Define multiple request types
interface GetUser extends Request.Request<User, UserNotFoundError> {
  readonly _tag: "GetUser"
  readonly id: string
}

interface GetUserPosts extends Request.Request<Post[], PostError> {
  readonly _tag: "GetUserPosts"
  readonly userId: string
}

const GetUser = Request.tagged<GetUser>("GetUser")
const GetUserPosts = Request.tagged<GetUserPosts>("GetUserPosts")

// Create resolver for users
const UserResolver = RequestResolver.makeBatched(
  (requests: GetUser[]) =>
    Effect.gen(function* () {
      const ids = requests.map(req => req.id)
      const users = yield* database.getUsersByIds(ids)
      const userMap = new Map(users.map(u => [u.id, u]))

      return Effect.forEach(requests, (req) => {
        const user = userMap.get(req.id)
        return user
          ? Request.succeed(req, user)
          : Request.fail(req, new UserNotFoundError({ userId: req.id }))
      })
    })
)

// Create resolver for posts
const PostResolver = RequestResolver.makeBatched(
  (requests: GetUserPosts[]) =>
    Effect.gen(function* () {
      const userIds = requests.map(req => req.userId)
      const posts = yield* database.getPostsByUserIds(userIds)
      
      // Group posts by userId
      const postsByUser = new Map<string, Post[]>()
      posts.forEach(post => {
        const existing = postsByUser.get(post.userId) || []
        postsByUser.set(post.userId, [...existing, post])
      })

      return Effect.forEach(requests, (req) =>
        Request.succeed(req, postsByUser.get(req.userId) || [])
      )
    })
)

// Compose resolvers for complex data fetching
const getUserWithPosts = (userId: string) =>
  Effect.gen(function* () {
    const user = yield* Effect.request(GetUser({ id: userId }), UserResolver)
    const posts = yield* Effect.request(GetUserPosts({ userId }), PostResolver)
    
    return { user, posts }
  })
```

#### Database N+1 Query Prevention

```typescript
// ❌ BAD: N+1 query problem (1 query for users, then N queries for posts)
const getUsersWithPostsBad = (userIds: string[]) =>
  Effect.gen(function* () {
    const users = yield* database.getUsersByIds(userIds)
    
    // This creates N separate database queries!
    const usersWithPosts = yield* Effect.all(
      users.map(user =>
        Effect.gen(function* () {
          const posts = yield* database.getPostsByUserId(user.id)
          return { user, posts }
        })
      )
    )
    
    return usersWithPosts
  })

// ✅ GOOD: Batched approach (2 queries total)
const getUsersWithPostsGood = (userIds: string[]) =>
  Effect.gen(function* () {
    // Single query for all users
    const users = yield* database.getUsersByIds(userIds)
    
    // Single query for all posts
    const allPosts = yield* database.getPostsByUserIds(userIds)
    
    // Group posts by userId in memory
    const postsByUser = new Map<string, Post[]>()
    allPosts.forEach(post => {
      const existing = postsByUser.get(post.userId) || []
      postsByUser.set(post.userId, [...existing, post])
    })
    
    return users.map(user => ({
      user,
      posts: postsByUser.get(user.id) || []
    }))
  })

// ✅ BEST: RequestResolver pattern (automatic batching + deduplication)
const getUsersWithPostsBest = (userIds: string[]) =>
  Effect.all(
    userIds.map(userId => getUserWithPosts(userId)),
    { concurrency: "unbounded" }
  )
```

```typescript
const chunk = <A>(array: A[], size: number): A[][] => {
  const chunks: A[][] = []
  for (let i = 0; i < array.length; i += size) {
    chunks.push(array.slice(i, i + size))
  }
  return chunks
```

### 11.2 Caching Strategies

Caching reduces expensive recomputations and external API calls by storing and reusing previously computed results.

#### Cache Module Fundamentals

```typescript
import { Effect, Cache } from "effect"

// Basic cache with TTL and capacity limits
const makeUserCache = Effect.gen(function* () {
  return yield* Cache.make({
    capacity: 1000,                    // Max 1000 entries
    timeToLive: "5 minutes",           // Entries expire after 5 minutes
    lookup: (userId: string) =>        // How to fetch missing values
      database.getUser(userId)
  })
})

// Use the cache
const program = Effect.gen(function* () {
  const cache = yield* makeUserCache

  // First call: Fetches from database
  const user1 = yield* cache.get("user-123")
  yield* Effect.logInfo("First call - database hit")

  // Second call: Returns cached value
  const user1Again = yield* cache.get("user-123")
  yield* Effect.logInfo("Second call - cache hit")

  // Different key: Fetches from database
  const user2 = yield* cache.get("user-456")
  yield* Effect.logInfo("Different key - database hit")
})
```

##### Cache-Aside Pattern

```typescript
// Application explicitly manages cache
const makeCacheAsidePattern = Effect.gen(function* () {

    capacity: 1000,
    timeToLive: "10 minutes",
    lookup: (id: string) => Effect.succeed(null as Product | null)
```

### 11.3 Concurrency Control

Proper concurrency control prevents resource exhaustion, ensures fair resource allocation, and maintains system stability under load.

```typescript
// Database connection pool
const makeDatabasePool = (config: PoolConfig) =>
  Effect.gen(function* () {
    const semaphore = yield* Semaphore.make(config.maxConnections)

    // Create pool of connections
    const connections = yield* Effect.all(
      Array.from({ length: config.maxConnections }, () =>

          Effect.sync(() => createConnection(config)),
          conn => Effect.sync(() => conn.close())

      use: (conn: Connection) => Effect.Effect<A, E, R>
    ): Effect.Effect<A, E, R> =>

          // Get next available connection (round-robin)

          return yield* use(connections[index])
        })
      )

// Worker pool for CPU-intensive tasks
const makeWorkerPool = (numWorkers: number) =>
  Effect.gen(function* () {
    const semaphore = yield* Semaphore.make(numWorkers)
    const taskQueue = yield* Queue.unbounded<Task>()

    // Worker processes
    const workers = Array.from({ length: numWorkers }, () =>
      Effect.gen(function* () {
        while (true) {
          const task = yield* Queue.take(taskQueue)
          
          yield* semaphore.withPermits(1)(
            Effect.gen(function* () {
              yield* processTask(task)
            })
          )
        }
      })
    )

    // Start all workers
    yield* Effect.forEach(
      workers,
      worker => Effect.forkDaemon(worker)
    )

    const submit = (task: Task) =>
      Queue.offer(taskQueue, task)

    return { submit } as const
  })

// Dynamic pool sizing based on load
const makeAdaptivePool = (minSize: number, maxSize: number) =>
  Effect.gen(function* () {
    const currentSize = yield* Ref.make(minSize)
    const semaphore = yield* Semaphore.make(maxSize)

    const adjustPoolSize = Effect.gen(function* () {
      while (true) {
        yield* Effect.sleep("30 seconds")
        
        const queueLength = yield* getQueueLength()
        const current = yield* Ref.get(currentSize)

        if (queueLength > current * 2 && current < maxSize) {
          // Scale up
          yield* Ref.update(currentSize, n => Math.min(n + 1, maxSize))
        } else if (queueLength < current / 2 && current > minSize) {
          // Scale down
          yield* Ref.update(currentSize, n => Math.max(n - 1, minSize))
        }
      }
    })

    yield* Effect.forkDaemon(adjustPoolSize)

    return semaphore
  })
```

#### Backpressure Handling

```typescript
// Bounded queue with backpressure
const makeBackpressureQueue = <A>(capacity: number) =>
  Effect.gen(function* () {
    const queue = yield* Queue.bounded<A>(capacity)

    const producer = (item: A) =>
      Effect.gen(function* () {
        // offer blocks if queue is full (natural backpressure)
        const success = yield* Queue.offer(queue, item)
        
        if (!success) {
          yield* Effect.logWarning("Queue full, request rejected")
          return yield* Effect.fail(new QueueFullError())
        }
      })

    const consumer = Effect.gen(function* () {
      while (true) {
        const item = yield* Queue.take(queue)
        yield* processItem(item)
      }
    })

    return { producer, consumer } as const
  })

// Sliding window with backpressure
const makeSlidingWindowLimiter = (windowSize: number, duration: Duration) =>
  Effect.gen(function* () {
    const requests = yield* Ref.make<Array<number>>([])

    const tryRequest = Effect.gen(function* () {
      const now = Date.now()
      const current = yield* Ref.get(requests)

      // Remove expired requests
      const withinWindow = current.filter(time => 
        now - time < Duration.toMillis(duration)
      )

      if (withinWindow.length >= windowSize) {
        return yield* Effect.fail(new RateLimitError({
          retryAfter: Duration.toMillis(duration)
        }))
      }

      // Add new request
      yield* Ref.set(requests, [...withinWindow, now])
      return Effect.void
    })

    return { tryRequest } as const
  })
```

#### Cache-Based Deduplication

```typescript
// Prevent concurrent identical computations
const makeDeduplicatingCache = <K, V, E>() =>
  Effect.gen(function* () {
    const cache = yield* Cache.make({
      capacity: 1000,
      timeToLive: "5 minutes",
      lookup: (key: K) => Effect.succeed(null as V | null)
    })

    const inProgress = yield* Ref.make<Map<K, Deferred.Deferred<V, E>>>(
      new Map()
    )

    const get = (key: K, compute: Effect.Effect<V, E>) =>
      Effect.gen(function* () {
        // Check cache first
        const cached = yield* cache.get(key)
        if (cached !== null) return cached

        // Check if computation is in progress
        const pending = yield* Ref.get(inProgress)
        const existing = pending.get(key)
        
        if (existing) {
          // Wait for in-progress computation
          yield* Effect.logInfo(`Deduplicating request for key: ${key}`)
          return yield* Deferred.await(existing)
        }

        // Start new computation
        const deferred = yield* Deferred.make<V, E>()
        yield* Ref.update(inProgress, map => new Map(map).set(key, deferred))

        // Compute value
        const result = yield* compute.pipe(
          Effect.ensuring(
            Ref.update(inProgress, map => {
              const newMap = new Map(map)
              newMap.delete(key)
              return newMap
            })
          )
        )

        // Notify waiting requests
        yield* Deferred.succeed(deferred, result)

        // Update cache
        yield* cache.refresh(key)

        return result
      })

    return { get } as const
  })

// Usage
const program = Effect.gen(function* () {
  const cache = yield* makeDeduplicatingCache<string, User, UserError>()

  // These concurrent requests will share computation

    cache.get("user-123", fetchUserFromDatabase("user-123")),
    cache.get("user-123", fetchUserFromDatabase("user-123")),
    cache.get("user-123", fetchUserFromDatabase("user-123"))
  ], { concurrency: "unbounded" })

  yield* Effect.logInfo("Only one database query executed")
})
```

#### Coordination Patterns for Shared Work

```typescript
// Share expensive computation among concurrent requests
const makeSharedComputation = <A, E>(
  computation: Effect.Effect<A, E>
) =>
  Effect.gen(function* () {
    const deferred = yield* Deferred.make<A, E>()
    const started = yield* Ref.make(false)

    const get = Effect.gen(function* () {
      const wasStarted = yield* Ref.modify(started, s => [s, true])

      if (!wasStarted) {
        // First request: start computation
        yield* Effect.fork(
          computation.pipe(
            Effect.flatMap(result => Deferred.succeed(deferred, result)),
            Effect.catchAllCause(cause => Deferred.failCause(deferred, cause))
          )
        )
      }

      // All requests await the same deferred
      return yield* Deferred.await(deferred)
    })

    return get
  })

// Usage: Multiple requests share one expensive computation
const program = Effect.gen(function* () {
  const getShared = yield* makeSharedComputation(
    Effect.gen(function* () {
      yield* Effect.logInfo("Starting expensive computation")
      yield* Effect.sleep("5 seconds")
      return "result"
    })
  )

  // All three requests wait for the same computation
  const [r1, r2, r3] = yield* Effect.all([
    getShared,
    getShared,
    getShared
```

### 11.5 Layered Caching

Multi-level caching provides optimal performance by combining fast local caches with slower but more durable distributed caches.

#### Multi-Level Cache Hierarchy

```typescript
// Three-tier caching strategy
const makeLayeredCache = Effect.gen(function* () {
  // L1: In-memory cache (fast, small, short TTL)
  const l1Cache = yield* Cache.make({
    capacity: 100,
    timeToLive: "1 minute",
    lookup: (key: string) => l2Cache.get(key)
  })

  // L2: Distributed cache (medium speed, larger, longer TTL)
  const l2Cache = yield* Cache.make({
    capacity: 10000,
    timeToLive: "10 minutes",
    lookup: (key: string) => l3Cache.get(key)
  })

  // L3: Database (slow, persistent)
  const l3Cache = yield* Cache.make({
    capacity: 1000000,
    timeToLive: "1 hour",
    lookup: (key: string) => database.get(key)
  })

  const get = (key: string) =>
    Effect.gen(function* () {
      // Try L1 first (fastest)
      const result = yield* l1Cache.get(key)
      yield* Effect.logTrace("Cache hit", { level: "L1", key })
      return result
    })

  const invalidate = (key: string) =>
    Effect.gen(function* () {
      // Invalidate all levels
      yield* l1Cache.invalidate(key)
      yield* l2Cache.invalidate(key)
      yield* l3Cache.invalidate(key)
      yield* Effect.logInfo("Cache invalidated at all levels", { key })
    })

  const refresh = (key: string) =>
    Effect.gen(function* () {
      yield* invalidate(key)
      return yield* get(key)
    })

  return { get, invalidate, refresh } as const
})
```

#### Consistency Strategies

```typescript
// Write-through consistency
const makeWriteThroughLayeredCache = Effect.gen(function* () {
  const l1 = yield* makeLocalCache()
  const l2 = yield* makeRemoteCache()
  const db = yield* Database

  const get = (key: string) =>
    Effect.gen(function* () {
      // Try L1
      const l1Result = yield* l1.get(key).pipe(Effect.option)
      if (Option.isSome(l1Result)) return l1Result.value

      // Try L2
      const l2Result = yield* l2.get(key).pipe(Effect.option)
      if (Option.isSome(l2Result)) {
        // Populate L1
        yield* l1.set(key, l2Result.value)
        return l2Result.value
      }

      // Fetch from database
      const dbResult = yield* db.get(key)
      
      // Populate both caches
      yield* Effect.all([
        l1.set(key, dbResult),
        l2.set(key, dbResult)
      ])

      return dbResult
    })

  const set = (key: string, value: unknown) =>
    Effect.gen(function* () {
      // Write to all levels synchronously
      yield* Effect.all([
        db.set(key, value),
        l1.set(key, value),
        l2.set(key, value)
      ])
    })

  return { get, set } as const
})

// Eventual consistency with background refresh
const makeEventuallyConsistentCache = Effect.gen(function* () {
  const l1 = yield* makeLocalCache()
  const l2 = yield* makeRemoteCache()
  const db = yield* Database

  const get = (key: string) =>
    Effect.gen(function* () {
      // Return L1 immediately if available
      const l1Result = yield* l1.get(key).pipe(Effect.option)
      if (Option.isSome(l1Result)) {
        // Background refresh from L2/DB
        yield* Effect.forkDaemon(refreshFromLower(key))
        return l1Result.value
      }

      // Not in L1: fetch from lower levels
      return yield* fetchFromLowerLevels(key)
    })

  const refreshFromLower = (key: string) =>
    Effect.gen(function* () {
      const l2Result = yield* l2.get(key).pipe(Effect.option)
      
      if (Option.isSome(l2Result)) {
        yield* l1.set(key, l2Result.value)
      } else {
        const dbResult = yield* db.get(key).pipe(Effect.option)
        if (Option.isSome(dbResult)) {
          yield* Effect.all([
            l1.set(key, dbResult.value),
            l2.set(key, dbResult.value)
          ])
        }
      }
    })

  const fetchFromLowerLevels = (key: string) =>
    Effect.gen(function* () {
      const l2Result = yield* l2.get(key).pipe(Effect.option)
      
      if (Option.isSome(l2Result)) {
        yield* l1.set(key, l2Result.value)
        return l2Result.value
      }

      const dbResult = yield* db.get(key)
      yield* Effect.all([
        l1.set(key, dbResult),
        l2.set(key, dbResult)
      ])
      return dbResult
    })

  return { get } as const
})
```

```typescript
// Profile operation performance
const profileOperation = <A, E, R>(
  name: string,
  operation: Effect.Effect<A, E, R>
): Effect.Effect<A, E, R> =>
  Effect.gen(function* () {
    const start = Date.now()
    
    const result = yield* operation
    
    const duration = Date.now() - start
    yield* Effect.logInfo(`${name} completed`, { duration: `${duration}ms` })
    
    return result
  }).pipe(
    Effect.withSpan(name, {
      attributes: { "operation.name": name }
    })
  )

// Benchmark multiple implementations
const benchmark = <A>(
  implementations: Record<string, () => Effect.Effect<A>>
) =>
  Effect.gen(function* () {
    const results: Record<string, number> = {}

    for (const [name, impl] of Object.entries(implementations)) {
      const start = Date.now()
      yield* impl()
      const duration = Date.now() - start
      results[name] = duration

      yield* Effect.logInfo(`${name}: ${duration}ms`)
    }

    // Find fastest
    const fastest = Object.entries(results).reduce((a, b) =>
      a[1] < b[1] ? a : b
    )

    yield* Effect.logInfo(`Fastest: ${fastest[0]} (${fastest[1]}ms)`)

    return results
  })
```

```typescript
/**
 * Performance Optimization Decision Tree
 * 
 * Use this guide to choose the right optimization strategy:
 * 
 * 1. BATCHING
 *    When: Multiple similar operations to external systems
 *    Example: N database queries, API calls
 *    Solution: RequestResolver with batching
 *    Benefit: Reduces network roundtrips, improves throughput
 * 
 * 2. CACHING
 *    When: Expensive computations repeated frequently
 *    Example: Database queries, API calls, CPU-intensive calculations
 *    Solution: Cache.make with appropriate TTL
 *    Benefit: Eliminates redundant work, faster response times
 * 
 * 3. CONCURRENCY CONTROL
 *    When: Risk of resource exhaustion
 *    Example: Database connections, HTTP requests
 *    Solution: Semaphore for rate limiting
 *    Benefit: Prevents overload, maintains stability
 * 
 * 4. DEDUPLICATION
 *    When: Concurrent identical requests
 *    Example: Multiple components fetching same data
 *    Solution: Effect.withRequestCaching
 *    Benefit: Prevents duplicate work, reduces load
 * 
 * 5. LAYERED CACHING
 *    When: Different performance/durability requirements
 *    Example: Local + distributed + database
 *    Solution: Multi-level cache hierarchy
 *    Benefit: Optimal performance at each level
 */

// Choose optimization based on characteristics
const selectOptimizationStrategy = (
  characteristics: {
    isExternal: boolean
    isExpensive: boolean
    isConcurrent: boolean
    hasRateLimit: boolean
    needsDurability: boolean
  }
) => {
  const strategies: string[] = []

  if (characteristics.isExternal) {
    strategies.push("batching")
  }

  if (characteristics.isExpensive) {
    strategies.push("caching")
  }

  if (characteristics.hasRateLimit) {
    strategies.push("rate-limiting")
  }

  if (characteristics.isConcurrent) {
    strategies.push("deduplication")
  }

  if (characteristics.needsDurability) {
    strategies.push("layered-caching")
  }

  return strategies
}
```

### Performance Optimization Summary

**Key Takeaways:**

1. **Request Batching**: Use `RequestResolver` to consolidate multiple requests into single operations, preventing N+1 query problems

2. **Caching**: Implement appropriate caching strategies (read-through, write-through, cache-aside) with proper TTL and capacity limits

3. **Concurrency Control**: Use `Semaphore` for rate limiting and resource pool management to prevent system overload

4. **Deduplication**: Enable request caching and deduplication to prevent redundant work from concurrent identical requests

5. **Layered Caching**: Implement multi-level cache hierarchies for optimal performance at different durability levels

6. **Measure First**: Always profile before optimizing, and monitor cache effectiveness with metrics

7. **Appropriate Limits**: Configure concurrency, cache size, and timeouts based on system capacity and requirements

**Performance Optimization Checklist:**

- [ ] Profile operations to identify bottlenecks
- [ ] Implement batching for external system calls
- [ ] Add caching with appropriate TTL for expensive operations
- [ ] Set concurrency limits to prevent resource exhaustion
- [ ] Enable deduplication for concurrent requests
- [ ] Implement cache invalidation strategy
- [ ] Monitor cache hit rates and adjust configuration
- [ ] Use layered caching for different performance requirements
- [ ] Benchmark different implementations
- [ ] Avoid premature optimization without measurements

By following these patterns and best practices, you can build high-performance Effect-TS applications that scale efficiently while maintaining code clarity and type safety.
